# Axion-Emulator

A neural network for predicting the non-linear matter power spectrum ratio $r(k) = P_{\rm ax}(k)/P_{\rm \Lambda CDM}(k)$ in cosmologies containing a mixture of cold dark matter (CDM) and ultralight axions (ULAs). 

The emulator takes a set of cosmological and axion parameters as input and predicts the corresponding non-linear matter power spectrum ratio over the range covered by the training set. 

## Paper
This repository contains the code and trained models associated with:

**D. Fremstad & H. A. Winther, "Emulating the Non-Linear Matter Power-Spectrum in Mixed Axion Dark Matter Models," Astronomy & Astrophysics 702, A120 (2025).**
[arXiv:2503.07277](https://arxiv.org/abs/2503.07277)

## Quick start
### Installation
Clone the repository and install the required Python packages:
```bash
git clone https://github.com/frdennis/Axion-Emulator.git
cd Axion-Emulator
```

```bash
pip install -r requirements.txt
```

The emulator can then be imported with:
```python
from src.axionemulator import AxionEmulator
```


### Making a prediction
The basic inputs to the emulator are 
``
[Omega_cdm, log10(A_s), log10(f_ax), log10(m_ax), z, log10(k)]
``
where:

* `Omega_cdm`is the CDM density parameter
* `A_s` is the primodial scalar amplitude
* `f_ax` is the axion fraction
* `m_ax` is the axion mass in eV
* `z` is the redshift
* `k` is the wavenumber in `h/Mpc`

For example:
```python
import numpy as np
from src.axionemulator import AxionEmulator
model = AxionEmulator(version=3)

# Cosmological parameters
Omega_cdm = 0.2637
A_s = 2.1e-9
f_ax = 0.5
m_ax = 1e-26
z = 0.0

# Wavenumbers
k = np.logspace(-2, 1, 100)

inputs = np.array([
        [
                Omega_cdm,
                np.log10(A_s),
                np.log10(f_ax),
                np.log10(m_ax),
                z,
                np.log10(ki),
        ]
        for ki in k
])
P = model.predictor(inputs)
```
See `example.ipynb` for a more complete set of examples, including predictions of ranges ofr axion masses, axion fraction, and wavenumbers. 
> Note: The exact input transformation should be kept consistent with those used during trainig. See the example notebook for details. 

## Model weights 

Several versions of the trained neural network are included in the repository. 

**Version 3 is recommended**, as it gives the lowest training and validation loss among the available versions. The corresponding weights are located in `emulators/lightning_logs/version_3`, which can be selected using `version=3` when creating an instance of the model.

## Generating simulation data

The repository also contains tools for generating the simulations used to train and test the emulator. `Generate.py` implements routines for generating `axionCAMB` initial conditions and running paired $N$-body simulations using the COLA method. 

The main functionality includes:
* `run_sim`: Run a pair of simulations for a specified set of cosmological and axion parameters.
* `make_LHS`: Generate a Latin hypercube sampling (LHS) of the desired parameter space.
* `run_pipeline`: Run the simulation pipeline for the parameter samples generated by `make_LHS`.
* `make_test_train`: Process the simulation results into a format suitable for training/testing an emulator.

For example: 

```python
from Generate import Generate

gen = Generate(label="my_sim",
        outputfolder="output_main",
        axioncamb_folder="axionCAMB",
        cola_folder="FML/FML/COLASolver",
        h = 0.72,
        Omega_b = 0.05,
        Omega_ncdm = 0.005,
        f_axion = 0.5,
        m_axion = 1e-27,
        boxsize=250.0,
        npart=640,
        ntimesteps=30,
        zini=30.0)

gen.run_sim()
```
This functionality is mainly intended for reproducing the simulation pipeline or generating new training data. It is not required for using the pre-trained emulator.
